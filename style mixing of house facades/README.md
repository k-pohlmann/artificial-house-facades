## Style Mixing of House Facades

In this folder, the dataset that was generated using the style mixing function of [StyleGAN2-ADA](https://github.com/NVlabs/stylegan2-ada-pytorch) ([model weights](https://drive.google.com/file/d/1TlfcCNWlt8lxPiFIlOwB2PxB7Jyt7CFi/view?usp=sharing)) is listed. Participants rated this dataset on the six dimensions of facelikeness, hominess, invitingness, relaxation, safety and price. 

Participants' ratings can be found in the csv file, which were collected in an online study (with a total number of 303 participants). Each image was rated on a 0-100 visual analogue scale by 10-12 participants. The provided rating is an average across all responses.
